# Tarea 2 — Resolución de problemas. Aplicaciones de probabilidad

## Español

Este repositorio contiene los archivos de entrega y los materiales reproducibles de la Tarea 2 de Matemáticas, realizada por Chanona Leyva José Luis.

### Contenido

- `documentos/Tarea_2_Matematicas.pdf`: versión PDF para entrega.
- `codigo/tarea2_analisis.R`: código R completo y comentado.
- `figuras/`: gráficas y fragmentos de código incluidos en los documentos.
- `tablas/`: datos y resultados exportados en CSV.

### Reproducción

1. Instalar R (versión 4.3 o posterior recomendada).
2. Abrir `codigo/tarea2_analisis.R` en RStudio o ejecutarlo desde R.
3. Ejecutar el script desde la carpeta del repositorio.
4. Las funciones utilizadas pertenecen principalmente a la instalación base de R; no se requieren paquetes externos.

El análisis de temperaturas usa únicamente los datos de Chiapas proporcionados para los años 1993–2023. El PCA de `USArrests` se realiza con centrado y estandarización para evitar que las escalas originales dominen el resultado.

## English

This repository contains the submission files and reproducible materials for Mathematics Task 2, prepared by Chanona Leyva José Luis.

### Contents

- `documentos/Tarea_2_Matematicas.pdf`: submission PDF.
- `codigo/tarea2_analisis.R`: complete and commented R code.
- `figuras/`: plots and code fragments included in the reports.
- `tablas/`: exported data and results in CSV format.

### Reproduction

1. Install R (version 4.3 or later is recommended).
2. Open `codigo/tarea2_analisis.R` in RStudio or run it from R.
3. Execute the script from the repository folder.
4. The script mainly uses base R functions; no external packages are required.

The temperature analysis uses only the supplied Chiapas data for 1993–2023. The `USArrests` PCA uses centering and standardization so that the original measurement scales do not dominate the result.
